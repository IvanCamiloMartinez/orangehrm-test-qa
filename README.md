# OrangeHRM – QA Automation

Proyecto de práctica de **Quality Assurance (QA)** enfocado en la automatización de pruebas sobre la aplicación web demo **OrangeHRM**.

El objetivo es aplicar conceptos de testing funcional y automatización utilizando **Selenium IDE** y **Cypress**, documentando los escenarios, casos ejecutados y resultados obtenidos.

## 🎯 Objetivo

Practicar y demostrar conocimientos en:

* Diseño y ejecución de casos de prueba.
* Pruebas funcionales.
* Automatización de pruebas web.
* Validación de resultados esperados.
* Identificación y documentación de errores.
* Uso de selectores y localizadores.
* Manejo básico de esperas y elementos dinámicos.
* Organización de pruebas automatizadas.

## 🧪 Herramientas

| Herramienta  | Uso                                            |
| ------------ | ---------------------------------------------- |
| Selenium IDE | Grabación y ejecución de pruebas automatizadas |
| Cypress      | Automatización de pruebas end-to-end           |
| JavaScript   | Lenguaje utilizado para las pruebas en Cypress |
| Git          | Control de versiones                           |
| GitHub       | Almacenamiento y documentación del proyecto    |

## 🌐 Aplicación bajo prueba

**OrangeHRM Demo**

La aplicación utilizada es una versión demo de OrangeHRM destinada a la práctica y demostración de pruebas.

Flujo principal trabajado:

**Login → Dashboard → Navegación por módulos**

## 📋 Pruebas realizadas

### Selenium IDE

Se realizaron pruebas mediante:

* Creación de Test Suites.
* Creación de Test Cases.
* Grabación de acciones sobre la aplicación.
* Ejecución y repetición de pruebas.
* Uso de comandos de interacción.
* Uso de assertions y validations.
* Identificación de elementos mediante selectores.

### Cypress

Se realizaron pruebas automatizadas utilizando:

* Estructura de tests `.cy.js`.
* `describe()` y `it()`.
* Localización de elementos.
* Interacciones con formularios y botones.
* Assertions.
* Navegación entre páginas.
* Validación de resultados esperados.
* Ejecución de pruebas desde Cypress.

## 🔎 Enfoque de testing

Las pruebas están orientadas principalmente a **testing funcional**, verificando que determinadas funcionalidades respondan de acuerdo con los resultados esperados.

Los casos incluyen escenarios positivos y negativos cuando resulta pertinente.
